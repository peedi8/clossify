# 시작 가이드 — 키 발급부터 첫 등록까지

> **2026-08-31 기준.** 네이버 커머스API센터의 절차·화면은 바뀔 수 있습니다.
> 이 문서와 실제 화면이 다르면 실제 화면이 맞습니다 — 이슈로 알려주시면 갱신합니다.

Clossify 는 서버·가입·결제가 없는 **로컬 도구**입니다. 필요한 것은
**네이버 커머스 API 키 2개**뿐이고, 그 키는 판매자 본인이 직접 발급합니다.
이 문서는 발급 과정에서 실제로 부딪히는 벽을 순서대로 안내합니다.

---

## 1. 시작할 수 있는지 먼저 확인 (30초)

아래에 하나라도 해당하지 않으면 **설치 전에** 해결해야 합니다.

- [ ] **국내** 개인사업자 또는 법인사업자의 스마트스토어가 있다
      (해외 개인·해외 사업자는 개발업체 계정 생성이 제한됩니다)
- [ ] 스토어가 **정상 상태**다 (심사중·거부·이용정지·탈퇴신청중이면 제한됩니다)
- [ ] 로그인할 계정이 그 스토어의 **통합매니저 권한**이다
  - 확인 위치: **스마트스토어센터 > 내정보 > 서비스 정보**
  - 권한이 없으면: 커머스API센터의 **통합매니저 위임프로세스**를 먼저 진행

## 2. 키 발급 (두 키가 같은 화면에서 함께 나옵니다)

1. **커머스API센터** 접속: <https://apicenter.commerce.naver.com/ko/member/home>
   — 통합매니저 계정으로 로그인
2. 첫 화면에 **"솔루션 마켓 입점"** 이 보여도 무시하세요.
   그건 솔루션을 판매하는 사업자용 경로입니다. 판매자 본인 키는
   메뉴의 **[애플리케이션] > [내스토어 애플리케이션]** 에서 발급합니다.
3. 애플리케이션 등록:
   - 개발업체 계정이 없다면 먼저 생성(계정명·장애대응 연락처·약관 동의)
   - **API 호출 IP 를 반드시 입력**하세요 — 이 도구를 실행할 PC 의 공인 IP 입니다.
     빠뜨리면 **키를 받아도 호출이 조용히 거부**되며, 화면에 원인이 나오지 않습니다.
   - 스토어당 애플리케이션은 **최대 1개**입니다
4. 발급된 **애플리케이션 ID** 와 **애플리케이션 시크릿**(`$2a$…` 형태)을 복사

## 3. 설치와 연결

```
pip install clossify        # 또는 저장소 클론 후 로컬 설치
```

MCP 호스트(클로드 등)에 서버를 등록한 뒤 대화에서 *"상품 등록하고 싶어"* 라고
말하면 설정 화면이 안내됩니다. 입력하는 값은 세 가지:

| 값 | 무엇 | 어디서 |
|---|---|---|
| 애플리케이션 ID | 키 ① | 2번에서 발급 |
| 애플리케이션 시크릿 | 키 ② | 2번에서 발급 |
| 스토어 주소 | 비밀 아님 | `smartstore.naver.com/여기부분` |

키는 **내 PC 의 설정 파일에만** 저장됩니다. 외부 서버로 전송되지 않습니다.

## 4. 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| "계정생성 대상이 아닙니다" | 통합매니저 권한 아님 | 1번 체크리스트의 권한 확인·위임 |
| 키는 받았는데 호출이 안 됨 | **API 호출 IP 미등록** (가장 흔함) | 애플리케이션 설정에서 현재 IP 등록 |
| 첫 화면이 "솔루션 마켓 입점" | 다른 경로의 랜딩 | 무시하고 [내스토어 애플리케이션] 메뉴로 |
| 등록 시 400 오류 | 필수 고시 항목 누락 | 오류 메시지에 부족한 필드가 표시됩니다 |

## 5. 이 도구가 하지 않는 것

- 키를 지어내거나 규제 신고값을 자동으로 채우지 않습니다 — 없는 값은 물어봅니다
- 서버로 데이터를 보내지 않습니다 — 네이버 API 직접 호출뿐입니다
- 아직 정식 릴리스가 아닙니다 — 현재 상태는 [README](../README.md)와
  [중간 보고서](PROJECT_REPORT.md)에 있습니다
