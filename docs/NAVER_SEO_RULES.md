# 네이버 쇼핑 검색 SEO 규칙서 (기준 문서)

> **기준일 2026-09-03** · 근거: 네이버 쇼핑검색 SEO 가이드 2025-03 (판매자센터 배포본, 27쪽) +
> 스마트스토어 판매자 FAQ(검색설정). 원문은 네이버 저작물이라 여기 싣지 않는다 — **우리 말로 추린 규칙**이다.
> 가이드가 바뀌면 이 문서를 갱신하고, 코드(상품명 조립·태그 생성·속성 매칭)는 이 문서를 계약으로 삼는다.
> 각 규칙 끝의 **[코드]** 는 자동 검사 대상, **[사람]** 은 사람이 판단할 항목이다.

## 0. 랭킹이 무엇으로 정해지나 (설계의 전제)
| 축 | 뜻 | 우리가 건드릴 수 있는 것 |
|---|---|---|
| 적합도 | 검색어와 상품정보의 일치 | 상품명·카테고리·브랜드·속성·태그 (텍스트 필드만 색인 — 상세 이미지는 색인 안 됨) |
| 인기도 | 최근 1개월 클릭·리뷰·판매·최신성 | 혜택·프로모션·빠른배송 (N+스토어는 검색 밖 판매도 반영) |
| 신뢰도 | 가이드 준수·어뷰징 없음 | 상품정보 정확성, 등록/삭제 반복 금지 |
| 선호도 | 사용자 개인화(N+스토어) | 없음 |

**한 줄**: 텍스트가 발견을 만들고, 이미지가 전환을 만든다.

## 1. 상품명
1.1 조립 순서: **브랜드 → 속성 → 카테고리(상품유형) → 시즌 → 속성 → 사이즈**. 예: `JAJU 극세사 무지 이불커버 Q 겨울용`. [코드]
1.2 카테고리(상품유형) 키워드는 **1~2개**. 동의어 나열(음료잔·커피잔·라떼잔·우유컵) 금지. [코드]
1.3 길이 **50자 이내 권장**, 100자 상한. [코드]
1.4 금지: 브랜드·카테고리 중복, 셀러명·몰명, 혜택·수식문구(무료배송·당일발송·할인·1위·인기·추천·정품·최고급…), 이미테이션 표현(~스타일·~st), 특수문자 남용(허용: `( ) - · [ ] / & + , ~ .`). [코드]
1.5 감성표현(복고풍·빈티지·감성…)은 상품명이 아니라 **태그**로. [코드]
1.6 조사·수식어("손잡이 있는", "예쁜") 금지 — 명사구로. [코드]
1.7 **사실과 달라선 안 된다** — 이름의 주장(손잡이 유무·소재·포함 여부)이 팩트와 모순이면 등록 전 사람 확인. [코드→사람]
1.8 옵션(색상·사이즈)은 옵션 필드로 등록하고 상품명엔 넣지 않는다. [코드]
1.9 이벤트·할인·배송·쿠폰·포인트 문구는 상품명 금지 → 구매/혜택 필드. [코드]

## 2. 카테고리
2.1 가장 구체적인 하위 카테고리로(포괄 상위 카테고리는 등록 불가). [코드]
2.2 카테고리가 고시 타입·KC 대상·속성 목록을 결정한다 → 확정 전엔 고시·속성을 확정하지 않는다. [코드]
2.3 자동 추천이 동점·애매하면 **사람이 고른다**(임의 확정 금지). [사람]

## 3. 브랜드 · 제조사
3.1 브랜드는 네이버 브랜드 사전의 **자동완성 항목을 선택**. 없으면 직접 입력. 판매처명·상호를 브랜드로 넣지 않는다. [사람]
3.2 제조사는 가전 등 중요 카테고리에서 필수. 사입품은 모르면 "상세페이지 참조"(실측: API 수용). [코드]

## 4. 속성
4.1 속성은 검색과 필터 양쪽에 쓰인다 — 정확히 많이 넣을수록 필터 상단. [코드]
4.2 찍을 수 있는 값은 **카테고리가 정의한 목록**뿐이다. [코드]
4.3 자동 매칭은 **명시된 긍정**만. 부정 근접("~불가", "미포함")은 자동 제외, 라벨 자체가 부정형이면 그 일치는 긍정. [코드]
4.4 대조 텍스트는 **팩트의 값과 전문**만 — 속성명("~포함 여부")은 대조 대상이 아니다. [코드]
4.5 옵션마다 갈리는 성격(세트/단품 등)은 옵션명으로 전역 매칭하지 않는다. [코드]
4.6 나열형 주장("전자레인지, 식기세척기, 오븐 사용 가능")은 각 항목에 분배한다. [코드]

## 5. 태그
5.1 태그 4유형: **사용용도(#캠핑용) · 시즌(#겨울용품) · 사용자(#신생아용품) · 감성(#레트로)**. 이 네 성격만. [코드]
5.2 금지: 상품명과 중복, 카테고리명, 브랜드명, 판매처명, 홍보문구(#무료배송 #할인). [코드]
5.3 태그 사전에 있는 것만 즉시 반영, 없으면 심사 — 사전 등재 여부는 판매자센터에서만 확인. [사람]
5.4 꼭 필요한 것만 — 과다 태그는 적합도 감점. 상한 10. [코드]

## 6. 이미지
6.1 대표이미지에 텍스트·워터마크·타 판매처 표시·허위 이벤트 부착 금지. 단색 배경에 상품 하나. [사람→코드 검토]
6.2 다량 상품 나열·상품 구분 어려운 이미지 금지. [사람]
6.3 상세 이미지는 검색 색인 대상이 아니다 — 전환용. 텍스트 정보는 이미지가 아니라 필드에. [코드]

## 7. 검색설정 (Page Title / Meta description) — FAQ 근거
7.1 `pageTitle` ≤100자, `metaDescription` ≤160자. 미입력 시 기본값(상품명 / 스토어 소개글). [코드]
7.2 상품별로 넣으면 검색엔진·SNS 카드뷰에 유리. 홍보문구 금지 원칙은 동일. [코드]

## 8. 혜택 · 인기도
8.1 구매/리뷰 포인트·즉시할인·프로모션은 N+스토어 랭킹에 반영된다 — SEO 축이다. [사람]
8.2 신규 등록은 한시적 최신성 점수. **등록/삭제 반복은 페널티**(인기도 복구 어려움) → 검증은 dry-run, 실등록은 판매 목적만, 테스트 상품은 삭제 대신 판매중지. [사람]

## 9. 신뢰도 · 어뷰징
9.1 상품정보와 다른 기재 = 랭크다운. AI 모니터링. 적발 2회 이상 영구 페널티. [코드+사람]
9.2 클릭·리뷰·판매 조작 금지. 상품 ID 재사용(다른 상품으로 교체) 금지. [사람]

## 부록 — 이 문서가 코드에서 참조되는 자리
상품명 조립·정제(`copywriting`·`seo`), 태그 생성, 속성 매칭(`attribute_suggestions`), 이름↔팩트 모순 게이트, 검색설정 생성.
규칙 번호(예: 5.2)를 테스트·티켓에서 인용한다.
