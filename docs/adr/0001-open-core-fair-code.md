# ADR-0001: 오픈코어 + fair-code 라이선스

- **상태**: 승인
- **날짜**: 2026-08-01

## 배경

Clossify는 원래 SaaS로 기획되었으나, 셀러 도구의 최대 진입 장벽이 **신뢰**(스토어 자격증명을 낯선 서비스에 맡기는 문제)임이 확인되었다. 로컬 실행 + 코드 공개는 이 장벽을 구조적으로 제거한다. 한편 파이썬 스택은 로컬 배포 시 소스가 노출되므로 "비공개 로컬 배포"는 실효가 없다 — 실제 선택지는 라이선스뿐이다.

## 결정

1. **오픈코어**: 등록 파이프라인(입력→상세페이지→SEO/고시→등록→재검증)은 이 저장소에 공개한다. 이미지 상세페이지를 편집 가능 문서로 복원·편집하는 엔진은 본 저장소에 포함하지 않는다(별도 제품). 단, 그 접점인 **scene.json 포맷 스펙은 공개**하여 생태계 호환을 보장한다.
2. **fair-code 계열 라이선스**(n8n Sustainable Use License 문안 기반) 채택: 개인·자사 사용 무료, 코드 열람 가능, 본 소프트웨어를 상업 서비스로 제공하는 권리는 저작권자 독점.
3. 문안은 창작하지 않고 검증된 기존 문안을 채택한다. 확정 전까지 저장소는 비공개이며 모든 권리 보유 상태를 유지한다.
4. 외부 기여 수용 시 CLA를 요구하여 재라이선스 권리를 보전한다.

## 결과

- 무료 사용자 = 배포망이자 QA망. 수익화는 서버 측 부가 서비스(편집 등)와 상업 라이선스로 이연.
- OSI 인정 "오픈소스(open source)" 명칭은 포기 (fair-code는 OSI 정의 밖이며, 본 저장소는 source-available 으로 표기한다).
