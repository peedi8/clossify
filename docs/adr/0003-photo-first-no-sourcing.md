# ADR-0003: 입력은 사용자 사진 — 소싱 레인 미포함

- **상태**: 승인
- **날짜**: 2026-08-01

## 배경

선행 코드베이스는 외부 마켓 URL 수집(유료 서드파티 API)·기계번역·외국어 텍스트 검출/제거를 포함한 소싱 레인을 중심으로 발전했다. 이 레인은 별도 유료 API 결제를 요구해 온보딩을 무겁게 하고, 엔진 코드의 약 36%를 차지하며, Clossify의 핵심 스토리("내 상품 사진으로 등록까지")와 무관하다.

## 결정

1. **v1 입력은 사용자 자신의 상품 사진 + 최소 3요소(가격 KRW·대표이미지·옵션)로 한정한다.**
2. 소싱 레인(외부 마켓 수집·번역·외국어 텍스트 제거 스택)은 이관하지 않는다. 별개 프로젝트로 취급한다.
3. 이에 따라 가격 산정은 KRW 직입력, 옵션은 사용자 입력 → 정규화 어댑터 경로로 재작성한다. 내부 식별자는 소싱 유래 키를 버리고 범용 `product_key`를 쓴다.

## 결과

- 온보딩에 필요한 유료 결제 0건 (네이버 API는 셀러 무료 발급).
- 무거운 OCR/인페인팅 의존성(rapidocr·paddle·tesseract·rembg) 제거로 설치가 가벼워진다.
- 향후 소싱이 필요해지면 별도 모듈/프로젝트로 접속한다 (본 저장소 스코프 밖).
