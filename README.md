# Clossify

> 사진 몇 장과 최소 정보만으로 — 상세페이지 생성부터 스마트스토어 실등록까지.

Clossify는 네이버 스마트스토어 셀러를 위한 **로컬 자동등록 엔진**입니다. MCP(Model Context Protocol) 서버로 동작하여, 사용자가 이미 쓰고 있는 MCP 지원 AI 클라이언트에 상품 등록 능력을 부여합니다.

- **입력**: 상품 사진 + 가격 · 대표이미지 · 옵션 (최소 3요소)
- **자동 처리**: 상세페이지 생성 → 상품명/SEO(검색광고 키워드 반영) → 상품정보제공고시 → 커머스 API 등록 → 등록 후 재검증
- **품질 게이트**: 이미지/카피/컴플라이언스 3분할 QA가 fail-closed로 등록을 막습니다
- **로컬 우선**: 서버 없음. 모든 자격증명은 사용자 PC의 설정 파일에만 존재하며, 사용자 컴퓨터에서 네이버 API로 직행합니다
