## 1. 금지어 (HARD — 위반 시 BLOCK)

## 2. 상세페이지 레이아웃 (HARD 락)
- **적용대상 = 상세(desc) 본문 이미지에만.** (옵션 선택 그리드는 §5가 관할 — 다열 허용, 위반 아님)
- 상세 본문 이미지: **단일 컬럼, width 100% 풀폭, 한 줄에 한 장, 세로로만 나열.**
- **금지(상세 본문 한정)**: 좌우배치 / 멀티컬럼 / masonry / grid 다열 / 이미지 축소해 옆에 붙이기.
- **판정 방식 = 코드 결정론**: 렌더된 `detail.html`에서 첫 `photo-stack`부터 `옵션 선택` 섹션 전까지 본문 영역만 검사한다. 이 영역에 `options-grid` / `display:grid` / `grid-template` / `column-count>1` / `flex-wrap` 마크업이 있으면 레이아웃 FAIL, 없으면 PASS.
- **비전 QA 제외**: 비전 모델은 본문 레이아웃을 눈으로 판단하지 않는다. 레이아웃 위반 여부는 HTML 코드검사 결과만 사용한다.
- 이미지 사이사이 **한글 기능설명** 블록.
- **원본 합성이미지 예외**: 원본 이미지 1장 안에 내부 grid/2x2 합성이 들어 있어도, 우리가 그 이미지를 풀폭 1장으로 올린 경우는 레이아웃 위반이 아니다. 우리가 쪼개서 grid 마크업으로 배치했는지만 코드로 판정한다.
- **옵션 그리드는 예외**: `옵션 선택` 섹션은 다열(2~N) 정상. QA는 옵션 그리드를 레이아웃 위반으로 보지 말 것.

## 3. 이미지 처리
- **제품이 보이면 전부 keep** (text/size_chart/notice여도). 순수 텍스트/공지/로고/blank만 제외.
- **중국어만 제거**:
  - 옵션 썸네일 = **로컬 OCR→번역→검은 라벨바에 한글 얹기**(정보성: 사이즈·상태) 또는 단순 덮기. API 0콜 지향.
  - 메인/상세 히어로컷 = API 인페인트(품질).
  - **셀러 워터마크(예 4815)는 그냥 냅둠**(번역·제거 안 함).
- **스튜디오샷/흰배경/배경제거/크롭 변환 절대 없음.** 비율 유지, 사이즈 축소만.
- 최종 모든 이미지 **중국어 0**.
- **과도 흰여백 트림(HARD)**: 이미지 상/하(좌우)에 **균일한 흰/거의흰 빈 여백이 과도**하면(예 높이의 12%↑) 자동 크롭. 특히 중국어를 지운 자리가 빈 흰공간으로 남는 경우 제거. 단 제품이 잘리면 안 됨(여백만). 트림 후 살짝(균등) 패딩만.
- **이미지 스케일 불변식(HARD — 근본규칙)**: 상세 캔버스 폭은 1000 고정. **제품 콘텐츠 폭은 [600 ~ 920] 밴드로 클램프**(`fit_to_canvas_width`가 유일 권한). 상한 920<1000이라 **항상 양쪽 흰 margin** — 콘텐츠가 캔버스 끝에 안 닿음(깔끔한 미감):
  - 네이티브 >920 → 920으로 **축소** + 필러박스. · 600~920 → 네이티브 유지 + **흰 필러박스**(가운데). · <600 → **600까지 완만 업스케일**(상한 2.0x, 920 절대 안 넘음) + 필러박스.
  - **너무 작은 원본 스킵**: 원본 최장변 <360px = 썸네일/아이콘 → **밴드에 안 넣고 제외**(뭉개느니 버림). 단 옵션 4×N 그리드는 별개(옵션 관할).
  - **절대 금지: 가는 조각을 풀폭으로 몇 배 업스케일**(트림이 만든 360px 화병을 1000으로 2.77배 부풀려 거대·픽셀깨짐 — 과거 버그).
  - **순서**: 트림은 정규화 *전에만*, fit은 항상 *마지막* 단계(fit 뒤 재-트림 금지). 中文 제거 후 트림했으면 **다시 fit**해 복귀.
  - **렌더 경계 강제(fail-closed)**: HTML 진입점(`build_detail_html`)에서 전 타일 `enforce_canvas_tiles` 통과 — 비순응 재-fit, 못 맞추면 **드롭**. 회귀 가드 `detail_tile_scale_violations`가 폭!=1000 잡아 자동 재-fit + QA 기록. 무음 통과 금지.
  - 옵션 썸네일 CSS=`object-fit:contain`(cover 금지 — crop/확대 방지). render 스크립트 기본폭=1000.

## 4. 카피 — 제목=기능, 본문=감성 허용 (하이브리드)
- **역할 분리**: 발견은 키워드로(제목), 구매결정은 감성으로(본문). 인테리어/소품은 감성구매 카테고리.
- **SEO 제목**: 기능·키워드만(§7). 감성표현 금지(제목 한정).
- **본문 카피**: **무드·감성 넉넉히 허용**(욕망 자극) + 기능·활용 녹임(스펙→혜택, [[COPY_GUIDE]] 훅/3단). "시간의 흔적이 느껴지는" "은은한 멋" 류 무드 표현 OK — 상품맥락에 닿으면 환영. 너무 빡빡하게 보지 말 것.
- **길이(HARD): 짧고 펀치있게.** 상세는 이미지라 모바일에서 긴 문단 금지. **밴드당 1~2문장**(리드 최대 3문장). **instructional/SEO 필러 꼬리 금지** — "~상세 이미지와 옵션에서 확인해 주세요", "크기·소재·사용 위치를 확인" 같은 안내문구·키워드 나열을 본문에 붙이지 말 것(그건 옵션/고시가 담당). 한 문장에 한 메시지.
- **본문 금지(좁게)**: ① **내용 0의 빈 마케팅 문구**("일상에 특별함을", "당신만을 위한" 류 어느 상품에나 붙는 공허한 말) ② **가짜통계**(재구매율·판매량 등 수치 지어내기) ③ 과장·정품주장(§1). → 이 셋만 NG, 나머지 감성은 통과.

## 5. 옵션
- **번호 매칭**: optionName `1.`,`2.` ↔ 상세 그리드 `①②③` (단일소스 option_number_records, 드롭다운=라벨 일치).
- **옵션명 = 중국어만 자연 번역 + 코드 그대로 유지** (`香槟色 MDYZ49`→`샴페인색 MDYZ49`, `MDYZ01`→`MDYZ01`). 커스텀/템플릿화 금지.
- **품절 반영**: 소싱 sku 품절(quantity 0) → 우리도 stock 0.
- **옵션 레이아웃 적응형**: 옵션이미지 비율 따라감(세로 길면 세로로, 크롭X). 열수 적응(2~N). 길어져도 됨.
- 옵션이미지 없으면: 번호+한글명+설명+계열톤 카드(폴백).
- **옵션 사이즈(범용 규칙 — 전 상품 동일)**: 사이즈는 *추출만, 지어내기·수동입력 절대 0*. 소스 우선순위 = 옵션이미지 OCR > 스펙시트 OCR > props (생 텍스트를 LLM이 포맷무관 읽음, 판매자별 파서 금지). **있으면 자동 표기, 없으면 그냥 "사이즈 정보 없음".** 추정·placeholder·수동요청 안 함.
