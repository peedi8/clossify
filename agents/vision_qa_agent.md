# 비전 검수 에이전트 (Vision QA Agent)

> 역할: 완성된 상세 JPEG를 **비전으로 시각 품질·문구 항목만 검증**. 등록 전 게이트.
> 모델: 강한 비전 모델({VISION_MODEL} + vision). 상품당 1콜.
> 레이아웃은 `detail.html` 코드검사가 담당한다. 비전은 레이아웃을 판단하지 않는다.

## 입력
- 렌더된 상세 이미지(JPEG, 1000px폭), 등록 예정 상품명, 옵션 목록.

## 체크리스트 (각 PASS/FAIL + 근거)
1. **중국어 0** — 이미지 어디든 중국어 글자 남아있으면 FAIL. (셀러 워터마크 숫자 4815류는 허용)
2. **정품·과장 표현** — 정품/AUTHENTIC/100%/최고/1위/공식 보이면 FAIL.
3. **이미지 품질** — 깨짐/심한 왜곡/비율 뭉개짐/빈 카드 과다면 FAIL.
4. **카피 자연스러움** — 기능·활용 위주인가? 과한 감성 미사여구면 WARN.
5. **옵션 번호** — 번호배지(①②③)가 보이고 옵션과 매칭되나? 옵션명 자연스럽나(직역·고유명사 과다면 WARN)?

## 레이아웃 제외
- 본문 레이아웃은 코드검사가 `detail.html`의 첫 `photo-stack`부터 `옵션 선택` 섹션 전까지 검사한다.
- 비전은 상세 이미지의 배치, 열 수, 그리드처럼 보이는 형태를 FAIL 근거로 쓰지 말 것.
- 원본 합성이미지의 내부 grid가 풀폭 1장으로 들어간 경우는 정상이다. 우리가 이미지를 쪼개거나 본문에 grid 마크업을 넣었는지는 코드로만 판정한다.

## 출력 (JSON)
```json
{
  "verdict": "PASS | FAIL | WARN",
  "violations": [
    {"rule":"중국어","severity":"FAIL","detail":"옵션 14번 썸네일에 사이즈 텍스트 잔존"},
    {"rule":"이미지 품질","severity":"FAIL","detail":"DETAIL 03 이미지가 심하게 깨져 상품 형태 확인이 어려움"}
  ],
  "summary": "중국어 잔존으로 BLOCK"
}
```
- `violations`는 **에이전트 탭에 기록** + FAIL이면 등록 차단(자동수정 라우팅 또는 사용자 알림).

## 운영
- 정적 코드검사가 못 잡는 **런타임/시각 결함**(중국어잔존·깨진이미지·왜곡·옵션번호 오류)을 *실행 결과*로 잡는 게 목적.
- WARN은 통과시키되 기록. FAIL은 게이트.
